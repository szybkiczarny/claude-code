# Sesja 2026-04-19

## Co robiliśmy
Budowa aplikacji **construct-web** — aplikacja dla kierowników budowy i deweloperów.

## Stack
- Vite + React + TypeScript + Tailwind CSS
- Supabase (auth + baza + storage)
- Groq Whisper (transkrypcja audio) + Groq LLaMA 3.3 70b (ekstrakcja danych)
- Projekt: `/home/kuba/CLAUDE_CODE/projects/construct-web/`

## Jak odpalić
```bash
cd /home/kuba/CLAUDE_CODE/projects/construct-web
npm run dev -- --host 0.0.0.0 --port 4000
# ngrok (HTTPS wymagany dla mikrofonu i aparatu):
ngrok http 4000
# URL: curl localhost:4040/api/tunnels
```

## Co działa ✅
- Auth (login/rejestracja)
- Projekty: lista + dodawanie własnych
- Nagrywanie głosowe → Groq Whisper → Groq LLaMA → Supabase
- AI wyciąga: lokalizację, usterki, podwykonawcę, deadline, powiadomienia
- Widok raportu: podsumowanie AI, lista usterek z detalami
- PDF: otwiera nową kartę z HTML + auto-drukowanie
- Email do podwykonawcy: mailto: z gotową wiadomością

## Wizja produktu
"Wirtualny sekretarz inżyniera budowy" — Zero-UI, głos + aparat.
Eliminuje 2h papierkowej roboty dziennie, ochrona prawna (GPS+timestamp),
szybka komunikacja do podwykonawców.
Killer features: AI analiza wizualna, wielojęzyczność PL→UA, alerty pogodowe.
